# Interview Revision

- Components: UI units with markup, state, parameters, and events.
- Binding: Synchronizes component properties and rendered controls.
- Lifecycle: Initialize with `OnInitializedAsync`; dispose managed resources.
- DI: Register services and inject them into components.
- Forms: Use `EditForm` and `DataAnnotationsValidator`.
- HTTP: Use injected typed HttpClient dependencies.
- EF Core: Use migrations, repositories, and `DbContext`.
- Security: Protect routes and enforce authorization on data operations.
- State: Select component, service, or persistent storage by lifetime.
- Rendering: Server circuits and WebAssembly have different state models.
